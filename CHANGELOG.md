# CHANGELOG

- Pass C function pointers to FFI tests and consumer checks on static musl; skip only the unsupported CLI symbol lookup.
- Export ELF CLI symbols for FFI symbol lookup.
- Port to Zig 0.17.0.
- Nested consumer builds preserve cache and toolchain environment paths and forward `-Dlua-root` under its declared name.
- `-Dlua-root` no longer infers an embedded root from `--prefix`; set it explicitly when needed.
- GNU-libc QEMU consumer targets now install instead of run because the nested build cannot receive the parent's `--libc-runtimes` path.
- Consumer builds install the package first so the nested build can use the parent prefix as a late-bound directory argument.
- Narrowed Linux generators follow Zig's automatic executor selection; `-fqemu` no longer forces QEMU for CPU-compatible 32-bit targets.
- Build 32-bit Linux host generators as static executables so 64-bit hosts can run them for 32-bit targets.
- `zig build consumer` forwards target, CPU, linkage, runtime, cache, Lua root, and prefix settings; it builds and installs when the host cannot execute the target.
- Corrected MIPS endianness and MIPS64R6 selection in generated VM code.
- Added `gcc_s` to ELF Unix library links and static pkg-config metadata.
- Added Mac Catalyst target handling and NetBSD ARM64 translation support for `__int128_t`.
- Added versioned shared-library names and SONAMEs matching the upstream LuaJIT release.
- Runtime loading excludes libc and fortified libc symbols from provider lookup across targets and optimize modes.
- Disabled only the shift-base sanitizer for the upstream ULEB128 decoder in native C builds.
- Added the `-Druntime=true` option for explicit process-lifetime loading, independent of linkage mode.
- Corrected runtime provider version validation to compare the numeric `lua_version()` result.
- Fixed `Thread` to retain the coroutine state created at construction.
- Added a typed Zig facade over the raw Lua 5.1 API for state ownership, standard libraries, protected chunk evaluation, stack values, and error retrieval.
- Added `-Dlinkage=static|dynamic`; static linkage is the default.
- Added a Zig build that compiles upstream LuaJIT C and generated VM inputs for the selected target.
- Added upstream LuaJIT 2.1.1788856981 as a Zig package.
